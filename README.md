# TravelSurvey

Мобильное приложение на .NET MAUI для создания анкеты путешественника.

## Функциональность
- Ввод личных данных
- Выбор страны и типа отдыха
- Выбор дополнительных услуг
- Настройка даты и бюджета поездки
- Добавление пожеланий
- Формирование итоговой анкеты
- Очистка формы

## Технологии
- C#
- .NET MAUI
- XAML
- Visual Studio 2022
